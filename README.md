# Signal

Signal is an Android network observation and diagnostics tool that connects cellular radio information, the active device network path, and real-world transfer tests.

The project is being rebuilt from an earlier cellular engineering prototype into a standard Android/Gradle application.

## Current scope

- cellular radio information (5G NR / LTE, band, PCI, TAC, NCI, RSRP/RSRQ/SINR where available)
- active network/interface observation
- ping and traceroute diagnostics
- provider-based real-world transfer tests
- GitHub Actions APK builds

Private deployment details, credentials, and private runtime topology are intentionally not stored in this public repository.
